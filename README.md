# MoceanAPI Skills

Agent skills that help coding agents build [MoceanAPI](https://www.moceanapi.com/) integrations using direct REST API calls.

## Installation

```bash
npx skills add moceanapi/skills
```

## Available Skills

| Skill | Description |
| --- | --- |
| [moceanapi-sms](skills/moceanapi-sms/SKILL.md) | Send SMS messages, track delivery, and handle inbound messages. |
| [moceanapi-whatsapp](skills/moceanapi-whatsapp/SKILL.md) | Send WhatsApp messages, manage templates, and handle replies and delivery updates. |
| [moceanapi-otp-verify](skills/moceanapi-otp-verify/SKILL.md) | Send, resend, and validate SMS one-time passwords (OTPs). |
| [moceanapi-voice](skills/moceanapi-voice/SKILL.md) | Build inbound and outbound call flows with speech, keypad input, and recordings. |
